# Maintainers

| Maintainer | GitHub | Areas |
|---|---|---|
| Elie Gambache | [@kdroidFilter](https://github.com/kdroidFilter) | Everything (lead) |

Maintainers review and merge pull requests, cut releases, and handle security reports (see [SECURITY.md](SECURITY.md)).
A release needs one maintainer; a change to the public API (`runtime/api`) or to the release workflows needs the
review of a maintainer other than its author, once the project has two.

Becoming a maintainer: regular, reviewed contributions over a few months, then an invitation from the current
maintainers. Each new maintainer is added here and to [.github/CODEOWNERS](.github/CODEOWNERS).
